# DXビジネス検定 学習管理 Web v2.7

**採点付き632問・用語カード196枚・提供画像の原文問題213枚**。前版v2.6を引き継いだ更新版です。

## v2.7の使い方（重要）

1. 「提供画像の原文演習」から問題セットを選択し、画像にある設問と4択を読んで回答番号を押します。画像は書き換えず、選択肢の順番も画像と同じです。
2. 原文問題の回答は、**公式の正答表が添付されていないため初期状態では採点しません**。選んだ番号・学習回数・迷いを保存します。公式教材で正答を確認したら「公式教材の正答を登録」から1〜4を入力でき、以後は自己登録正答との一致・不一致を表示します。
3. 「対策強化問題」には、元の設問を転記せず新規作成した**47問**を収録。こちらは採点・各選択肢の理由・復習に対応しています。
4. 「学習履歴」には、従来の演習履歴に加え、原文画像の直近20件の回答履歴も表示します。

## v2.7で追加したもの

- 過去の3つと今回のZIPを照合し、スクリーンショット**213枚**を原画像のまま重複除去して収録（11/12午前以前93枚＋11/12午後60枚＋11/18新規60枚）。今回のZIPの120枚中60枚は既提供の画像と同一です。
- 原文を確実に維持するため、OCRで誤字を起こすテキスト転記は行っていません。原文画像の選択肢は固定の1〜4で回答します。
- 独自の対策強化問題47問（Q586〜Q632）を追加。近接概念・誤答理由・ケース比較を強化。2026年改訂シラバスのMCP、RAG、AIエージェント、GEO/AEO、バイブコーディングも含みます。
- Googleログイン・Firestore同期に、原文画像の回答記録と自己登録正答を追加。既存キーと旧履歴の互換性を維持しました。

**公開時の注意：**原文画像は購入教材に由来する可能性があります。画像ファイルは静的アセットで、Googleログインによる「履歴同期」だけでは第三者の閲覧を防げません。利用条件を確認のうえ、アクセス制限された個人環境で使用してください。現行の一般公開サイトへそのままデプロイすることは推奨しません。

**採点の注意：**原文画像には正答データがなく、予測した回答を「正解」として入力していません。適切な正答照合には、公式教材の解答表が必要です。

## 問題の品質・位置づけ

- v2.7の新規47問は、**スクリーンショットの文面を複製したものではありません**。新規の設問・選択肢・解説を作成。原文画像は別画面でそのまま閲覧できます。
- v2.7追加の47問は正解位置1〜4の内訳が13／13／11／10問。採点付き問題は表示時に選択肢の並びをランダム化。
- 誤答には各選択肢に対応する理由を用意。
- 企業・サービス固有の機能は公開情報に基づき作問。料金・数値など変動しやすい細部は出題対象外とした。
- 新規の採点付き問題は公式問題ではなく、出題・700点到達を保証するものではありません。公式eラーニングを主教材として併用してください。
